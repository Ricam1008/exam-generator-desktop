# Product

Exam Generator Desktop is a local-first Mac study tool for university students. Students select documents, review extraction, generate source-backed practice exams, and resume local study attempts.

Input: PDF, DOCX, PPTX, text/Markdown and scanned images. AI: Ollama, DeepSeek, custom compatible APIs and official ChatGPT plan access where eligible. The interface defaults to German; exams support German and English.

Original material stays unchanged. Cloud text generation is an explicit choice; OCR is local. Credentials belong in the platform's protected store. No automatic paid fallback, cloud sync, LMS, analytics or hosted service.

Keep the task flow practical: Material, Prüfung erstellen, Lernen, Einstellungen. Technical tuning stays out of the student flow.
